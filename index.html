02 / THE SETUP

Three tiny decisions.

The whole stack is intentionally boring. Boring is fast, cheap, reliable, and easy to understand six months from now.

01

Buy the address

Porkbun or Cloudflare Registrar. The only recurring cost is the domain registration.

02

Host the files

GitHub Pages serves the site for free and gives it a default .github.io address.

03

Keep the files small

One index.html, one style.css, zero images, zero JavaScript, zero drama.

04 / THE FREE VERSION

Technically, it can be $0/year.

If you do not care about owning harrisonoconnorhoover.com, skip the domain entirely and use a free GitHub Pages address.

harrisonoconnorhoover.github.io harrisonoconnorhoover.pages.dev

But for eleven bucks a year, the .com is a pretty good deal for a permanent little corner of the internet.
